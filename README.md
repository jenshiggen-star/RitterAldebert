# RitterAldebert

Persönliche Homepage im Zeitungsstil. Reines HTML/CSS, gehostet über GitHub Pages.

- Lokal ansehen: `python3 -m http.server 8000` → http://localhost:8000
- Links prüfen: `python3 scripts/check_links.py`
- Veröffentlichen: `git add -A && git commit -m "…" && git push`

Arbeitsanweisungen für Claude Code: siehe `CLAUDE.md`, Gestaltung: `docs/design.md`.
